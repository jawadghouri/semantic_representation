================================================================================
WHAT'S GENERATED
================================================================================

4 plot types (each with normalized + unnormalized versions):

1. HEATMAPS (model-centric)
   └─ {model}_heatmap_{norm/unnorm}.png
   └─ Shows: pairwise distances between all responses
   └─ Use: Verify group structure in embedding space

2. 2D PCA (paragraph-centric, Option A)
   └─ {R_id}_pca2d_{norm/unnorm}.png
   └─ Shows: where each response sits in model's 2D PCA space
   └─ Use: Quick 2D visualization of response positions

3. 3D PCA (paragraph-centric, Option A)
   └─ {R_id}_pca3d_{norm/unnorm}.png
   └─ Shows: where each response sits in model's 3D PCA space
   └─ Use: Reveal hidden structure not visible in 2D

4. BAR CHARTS (prompt-response distances)
   └─ {llm}_{model}_prompt_response_{norm/unnorm}.png
   └─ Shows: distances from prompt to each response
   └─ Use: Measure which LLM/embedder best preserves prompt topic

FILE NAMING CONVENTION
================================================================================

Expected format for embeddings:
  {response_id}_{model_name}.npy              (unnormalized)
  {response_id}_{model_name}_norm.npy         (normalized, optional)

Example:
  R1_bge.npy
  R1_bge_norm.npy
  R1_minilm.npy
  R1_minilm_norm.npy
  R1_e5.npy
  R1_e5_norm.npy
  prompts_bge.npy                             (optional, for prompt-response analysis)

The pipeline auto-detects which models are available based on files found.

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "ModuleNotFoundError: No module named 'visualization'"
→ Fix: export PYTHONPATH="/path/to/aporia_isolated_work:$PYTHONPATH"
→ Or:  python -m visualization.heatmap_plots (use -m flag)

Issue: "FileNotFoundError: No such file or directory: 'data/processed/embeddings/'"
→ Fix: Verify embeddings are copied/symlinked to data/processed/embeddings/
→ Check: ls -la data/processed/embeddings/

Issue: "Warning: not enough data for 2D/3D PCA"
→ Fix: Need at least 2 embeddings per model (heatmap), 3+ for 3D PCA
→ Check: All your response IDs are in config/groups.py GROUP_CONFIG?

Issue: Plots are blank or missing annotations
→ Fix: Verify GROUP_CONFIG IDs match your file names exactly (case-sensitive)
→ Check: R1 in config must match R1_bge.npy in folder

Issue: "matplotlib.figure.Figure" errors or slow performance
→ Note: Normal for 100+ responses; heatmap annotation O(N²)
→ Solution: Reduce figsize or number of annotated values for large datasets
